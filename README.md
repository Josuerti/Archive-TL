# Archivo de transformaciones 2D

Este repositorio conserva el archivo `Proyecto_Transformaciones_2D (1).html` como referencia histórica. Su tamaño es de aproximadamente 1,5 MB.

Para consultar el proyecto organizado en HTML, CSS y JavaScript, utiliza [transformaciones-2d-algebra](https://github.com/Josuerti/transformaciones-2d-algebra).

## Consultar el archivo

Descarga `Proyecto_Transformaciones_2D (1).html` y ábrelo en un navegador. Este repositorio no dispone de una entrada `index.html`. No se ha comprobado la ejecución de esta copia histórica.

## Mantenimiento

Las correcciones activas de transformaciones se preparan en el repositorio enlazado. Esta copia se conserva sin sustituirla ni eliminarla para mantener la referencia original.
